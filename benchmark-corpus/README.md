# Корпус производительности Takt

Этот каталог описывает воспроизводимые медиа для этапа 9, но не принимает
случайные пользовательские файлы. До добавления каждого образца необходимо
зафиксировать источник, лицензию, размер и SHA-256.

Локальные файлы помещаются в `benchmark-corpus/files/`, а их описание — в
`benchmark-corpus/manifest.local.json`. Оба пути исключены из Git, пока не выбран
свободно распространяемый финальный набор. Проверка:

```powershell
.\scripts\verify-benchmark-corpus.ps1
```

Минимальная запись манифеста:

```json
{
  "schema": 1,
  "corpus_id": "takt-local-1",
  "files": [
    {
      "id": "audio-no-artwork",
      "path": "files/audio-no-artwork.flac",
      "media_kind": "audio",
      "container": "flac",
      "video_codec": null,
      "audio_codec": "flac",
      "width": null,
      "height": null,
      "fps": null,
      "features": ["artwork:none", "lossless"],
      "size_bytes": 123456,
      "sha256": "64 HEX SYMBOLS",
      "license": "CC0-1.0",
      "source": "https://example.invalid/source"
    }
  ]
}
```

Целевая матрица перед baseline 1.0:

- аудио без обложки, с обычной и крупной допустимой обложкой;
- 1080p и 4K; 24, 30 и 60 fps;
- H.264, HEVC, VP9 и AV1 — только если декодер входит в выбранную релизную поставку;
- субтитры, несколько дорожек, главы и Unicode-метаданные;
- отдельные явно повреждённые файлы для обработки ошибок;
- lossless и пара соседних gapless-файлов;
- длинные имена проверяются генерируемым локальным fixture, а не дублированием
  большого медиафайла.

Манифест не является доказательством лицензии. Перед публикацией файлы и условия
их распространения входят в общий compliance-check этапа 10.
