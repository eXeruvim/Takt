# Измерения Oxide

Производительность измеряется в отдельном профиле `profiling`: это release-сборка
с символами для профилировщика. Debug-запуск через `cargo run` не подходит для
сравнения CPU, памяти или задержек.

## Быстрый сценарный замер

1. Соберите неизменённый commit:

   ```powershell
   cargo build --profile profiling --locked --offline
   ```

2. Запустите один сценарий, например двухминутное воспроизведение аудио:

   ```powershell
   .\scripts\measure-oxide.ps1 -Scenario audio -DurationSeconds 120
   ```

   Для стандартной профильной сборки скрипт при необходимости копирует корневой
   `mpv-2.dll` рядом с executable под ожидаемым загрузчиком именем
   `libmpv-2.dll`. Нестандартный executable должен поставляться со своей DLL.

3. Скрипт откроет Oxide. Настройте указанный сценарий, дождитесь стабилизации и
   нажмите Enter в терминале. Во время записи не выполняйте посторонних действий;
   оставшееся время отображается индикатором в терминале.

Доступные сценарии: `idle`, `audio`, `video-1080p`, `video-4k`,
`large-playlist`, `large-artwork`. Аппаратное декодирование и тему фиксируйте
в имени или заметке к результату и не меняйте внутри одного замера.

Сырые образцы сохраняются в `benchmark-results/*.csv`, сводка — в JSON рядом.
Каталог исключён из Git: он содержит характеристики конкретного компьютера.
JSON фиксирует commit, чистоту рабочего дерева, версии Rust/Cargo, хеши
`Cargo.lock` и `mpv-2.dll`, ОС, CPU и GPU. CPU нормирован к суммарной мощности
всех логических процессоров, то есть близок к представлению Диспетчера задач.

Самопроверка без запуска окна:

```powershell
.\scripts\measure-oxide.ps1 -Scenario idle -ValidateOnly
```

## Правила сравнения

- Сравнивайте только одинаковые файлы, настройки, питание, размер окна и backend.
- Выполняйте минимум пять прогретых запусков каждого варианта; храните все выбросы.
- Cold start процесса и холодный файловый кэш — разные эксперименты.
- Working set может меняться из-за системного кэша. Для утечки важнее устойчивый
  рост private bytes, handles или threads после одинаковых завершённых циклов.
- Итоговый baseline 1.0 требует также frame-time/GPU-метрик из внешнего
  профилировщика; этот скрипт их не подменяет.
