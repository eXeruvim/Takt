# Oxide

Oxide — Windows-first медиаплеер для видео и аудио на Rust, Slint и libmpv. Цель
проекта — надёжное локальное воспроизведение, управление с клавиатуры и
собственная дизайн-система, вдохновлённая принципами Raycast, без копирования его
бренда и закрытых ассетов.

> Проект находится на ранней стадии разработки. Базовое воспроизведение работает,
> но упаковка зависимостей, новый рендеринг и полный UI ещё не завершены.

## Реализовано

- открытие локального видео и аудио;
- play, pause, stop и перемотка;
- громкость, mute, скорость и повтор файла;
- смешанный плейлист видео и аудио из папки в естественном порядке;
- отдельный адаптивный аудиорежим;
- распространённые lossless-форматы (FLAC, ALAC/M4A, WAV/AIFF, APE, WavPack,
  TTA) и безопасные gapless-переходы между совместимыми треками;
- аудиотеги и встроенные обложки;
- выбор аудио- и субтитровых дорожек, загрузка внешних субтитров;
- таймер и базовые свойства медиа;
- полноэкранный режим и горячие клавиши;
- передача событий и ошибок libmpv в UI.
- экспериментальная контекстная конвертация через отдельный процесс FFmpeg:
  видео в MP4/H.264, MP4/H.265 и WebM, аудио в MP3, M4A/AAC, FLAC, WAV и Opus,
  а также уменьшение размера и remux без перекодирования.

## Требования

- Windows 10 или новее;
- стабильный Rust toolchain;
- совместимая библиотека libmpv (`mpv-2.dll` во время запуска);
- FFmpeg в `PATH`, рядом с `oxide.exe`, в подпапке `tools` или по пути из
  `OXIDE_FFMPEG` — только для конвертации;
- рабочая C/C++ link-среда для выбранного Rust target.

Поставка libmpv вместе с приложением пока не автоматизирована. Это обязательная
задача перед первым публичным релизом.

## Сборка

```powershell
cargo build
cargo run
```

Проверки проекта:

```powershell
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets --all-features
cargo test --locked -p libmpv --lib ownership_tests
```

Для `libmpv` используется локальное исправление закреплённого исходного кода
в `vendor/libmpv`: освобождение контекста при ошибке initializer и строковых
буферов при невалидном UTF-8. Происхождение и отличия описаны в
[vendor/libmpv/OXIDE_PATCH.md](vendor/libmpv/OXIDE_PATCH.md).
Нативная DLL не менялась. Проверки `ownership_tests` используют её без окна,
загрузки медиа и вывода звука; общий набор тестов Oxide их автоматически не запускает.

Проверки `converter::lifecycle_tests` входят в общий набор: они запускают копии
тестового executable вместо FFmpeg, проверяют зависание, отмену, ошибки, panic и
очистку процессов/временных файлов, без UI и реальных медиа. Единственный
`ignored`-тест `helper_child` — точка входа этих subprocess fixtures, которую
остальные тесты запускают явно; отдельно запускать `--ignored` не требуется.

## Завершение конвертации и приложения

Обнаружение FFmpeg ограничено тремя секундами и 64 КиБ суммарного вывода на
каждый проверяемый путь. Выход из приложения прерывает проверку. У самой
конвертации общего тайм-аута нет: отмена работает и при отсутствии прогресса.
Вывод читается без отдельных reader-потоков; размер строки ограничен 8 КиБ,
накопленная диагностика — 32 КиБ. Задача владеет процессом и временным результатом,
dispatcher — её потоком. Ошибка или panic освобождает очередь для следующей задачи.

На Windows FFmpeg включается в Job Object с остановкой при закрытии handle:
отмена и выход останавливают его и присоединённых потомков. После запроса
остановки ожидание прямого дочернего процесса ограничено двумя секундами.
Присоединение выполняется сразу после `spawn`; это не sandbox и не гарантия
перехвата потомков, успевших появиться до присоединения.

После завершения UI приложение ждёт фоновые потоки до пяти секунд. Если вызов
ОС/libmpv остался заблокирован, процесс выходит с ошибкой вместо бесконечного
ожидания. При таком аварийном выходе сохранение последних позиций и удаление
временного файла не гарантируются. Проверка реальной конвертации и выхода через
интерфейс выполняется вручную. Unix-ветка управления группой процессов пока не
проверена на целевой ОС; переносимость остаётся отдельной задачей.

## Основные клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+K` | Открыть палитру команд |
| `Ctrl+O` | Открыть файл |
| `Ctrl+Shift+O` | Открыть папку |
| `Ctrl+L` | Открыть плейлист |
| `Space` или `K` | Play / pause |
| `J` / `L` | Назад / вперёд на 10 секунд |
| `←` / `→` | Назад / вперёд на 5 секунд |
| `↑` / `↓` | Изменить громкость |
| `M` | Mute |
| `R` | Повтор текущего файла |
| `S` | Остановить воспроизведение |
| `F` | Полноэкранный режим |
| Двойной клик по видео | Полноэкранный режим |
| `N` / `P` | Следующее / предыдущее видео |
| `I` | Информация о медиа |
| `H` | Справка по клавишам |
| `O` | Открыть файл |

Буквенные сочетания привязаны к физическим клавишам и работают одинаково в
английской, русской и других раскладках. Откройте «Команды и горячие клавиши»
кнопкой клавиатуры или `Ctrl+K`. Первый клик по другой строке выбирает команду;
повторный клик по выбранной строке (или `Enter` в поиске) запускает её.
Клик по полю горячей клавиши или `F2` раскрывает редактор под выбранной строкой:
поле записи с приглашением «Нажмите сочетание на клавиатуре» и движущейся
пунктирной обводкой. Кнопка «Сохранить» появляется внутри поля справа только
после ввода допустимого сочетания, отличающегося от текущего.
Текущее назначение и восстановление исходного сочетания расположены в шапке
двумя колонками: подпись сверху, значение в компактной плашке по центру ниже. Вся колонка восстановления
доступна для нажатия. Шапка и редактор объединены общим внешним контуром.
Во время редактирования текущее сочетание показано компактной подписью в шапке;
акцентный фон выделяет только шапку, а «Сохранить» получает акцент после допустимого ввода.
Соседние строки плавно сдвигаются, а список прокручивается так, чтобы редактор
оставался видимым. Пока новое сочетание не введено, повторный клик по раскрытой
строке закрывает редактор, клик по другой строке выбирает её, а клик по её
сочетанию начинает его запись. При попытке перейти с несохранённым вводом
редактор остаётся открыт: предупреждение временно заменяет сочетание в поле,
дважды плавно пульсирует и исчезает, возвращая введённое значение. Только пока
предупреждение отображается, следующий клик по другой команде отменяет ввод и
выполняет переход; клик по текущей команде оставляет редактор открытым. Когда
предупреждение исчезло или ввод изменился, подтверждение сбрасывается: следующий
клик снова сначала покажет предупреждение.
Пока предупреждение видно, кнопка «Сохранить» скрыта. При уменьшении движения
предупреждение показывается без пульсации и затем скрывается.
Клик за пределами окна при несохранённых изменениях запускает закрытие через три
секунды. Основное содержимое размывается, по центру появляется предупреждение
с отсчётом рядом с «Закрыть меню» и плавно убывающей полоской. Размытие использует
однократный снимок модального окна в памяти; файл изображения не создаётся.
«Закрыть меню» отменяет черновик и закрывает меню сразу;
«Отменить закрытие» или `Esc` останавливает отсчёт и возвращает к тому же черновику.
Повторный клик снаружи не перезапускает таймер. Отсчёт идёт по прошедшему времени
и продолжается при переключении фокуса на другое приложение. Без изменений
клик снаружи закрывает окно сразу, даже если редактор открыт.
В списке выбранное поле отмечено статичной акцентной рамкой. Marching Ants
работает только в поле записи во время ожидания ввода; при включённом
уменьшении движения обводка остаётся неподвижной. Ввод текущего назначения
не считается изменением и не требует сохранения.
Проверьте сочетание и нажмите «Сохранить»;
`Esc` отменяет ввод и оставляет прежнее назначение. Для занятого сочетания вместо
«Сохранить» доступно явное действие «Переназначить». До нажатия поле предупреждает,
какая команда останется без горячих клавиш. После подтверждения её назначения
(включая альтернативные клавиши) очищаются, а выбранная команда получает сочетание.
Оба изменения сохраняются между запусками; пустое назначение не заменяется
стандартным при загрузке. Простое введение занятого сочетания ничего не меняет.
`Tab` завершает запись и переводит фокус к кнопкам.
Свободное сочетание подсвечивается зелёным, занятое — красным. Пояснение конфликта
показывает занятое значение и последствия переназначения прямо в поле ввода,
плавно пульсирует, затем остаётся рядом с кнопкой. Новое значение можно ввести сразу, не дожидаясь
окончания анимации. Название редактируемой команды и ошибка внизу не дублируются;
там остаётся выровненное по центру короткое пояснение и отдельные обозначения доступных клавиш:
`Enter`, `F2`, `Esc` при выборе команды; `Tab`, `Esc` при редактировании.
Пока поле ввода в фокусе, каждое новое
сочетание заменяет предыдущее — и свободное, и занятое — без предварительного клика.
Удержание клавиши не повторяет запись; `Tab` переводит фокус к действиям и
приостанавливает такой ввод, чтобы `Enter`/`Space` могли активировать кнопку.
Чтобы вернуться к вводу после кнопок, сфокусируйте поле кликом или через `Tab`.
Клик по полю сохраняет черновик, пока не нажато новое сочетание.
Действие «Восстановить …» с
исходным сочетанием в подписи появляется в шапке, когда сохранённое назначение или
введённый вариант отличается от исходного. Оно подставляет исходное сочетание;
сброс применяется после нажатия «Сохранить»;
общий сброс требует отдельного подтверждения. Изменения сохраняются между запусками.
